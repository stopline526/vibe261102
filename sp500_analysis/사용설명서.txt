S&P 500 Analyzer - 사용설명서
================================

S&P 500 과거 시세 CSV를 불러와 데이터를 정제하고, 기간별로 다각도 분석한 뒤
종가 라인그래프·분석 차트·표·리포트로 보여주는 프로그램입니다.
파이썬 설치 없이 SP500Analyzer.exe 하나로 실행됩니다.


1. 실행 방법
------------
1) 압축을 원하는 폴더에 풉니다.
2) SP500Analyzer.exe 를 더블클릭합니다.
   - 첫 실행은 압축 해제와 백신 검사 때문에 10~20초 정도 걸릴 수 있습니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행]을 누르세요.
     (코드 서명 인증서가 없는 개인 제작 프로그램이라 표시되는 경고입니다.)


2. 준비할 데이터
----------------
인베스팅닷컴(kr.investing.com) S&P 500 "과거 데이터" 페이지에서 내려받은 CSV 형식입니다.
첫 줄(컬럼)이 아래와 같아야 합니다.

    "날짜","종가","시가","고가","저가","거래량","변동 %"

다운로드 폴더에 "S&P 500 과거 데이터.csv" 가 있으면 실행할 때 자동으로 불러옵니다.


3. 사용 순서
------------
1) [파일 열기] 로 CSV를 선택합니다.
2) 기간(시작일 ~ 종료일)을 고릅니다. 기본값은 2000-01-01 ~ 2019-12-31 입니다.
3) [분석 실행] 을 누르면 상단 요약 카드와 아래 탭이 채워집니다.
   - 종가 라인그래프 : 마우스를 올리면 날짜·종가 표시, 툴바로 확대/이동
   - 다각도 분석     : 이동평균, 연도별 수익률, 낙폭, 변동성, 수익률 분포, 월별 평균
   - 연도별 성과 / 월별 계절성 : 머리글을 누르면 정렬
   - 분석 리포트     : 정제 과정과 전체 분석 결과 텍스트
   - 정제 데이터     : 정제된 일별 데이터
4) [결과 저장] 으로 폴더를 고르면 아래 파일이 저장됩니다.
   - sp500_close_기간.png      종가 라인그래프
   - sp500_dashboard_기간.png  다각도 분석 차트
   - sp500_cleaned_기간.csv    정제 데이터 (엑셀에서 바로 열림)
   - sp500_report_기간.txt     분석 리포트


4. 데이터 정제 내용
-------------------
- 숫자 속 콤마(,)와 % 기호 제거, 날짜 형식 통일
- 비어 있는 거래량 컬럼 제거, 결측/중복 날짜 제거
- 고가가 시가보다 낮은 등 논리 오류 행은 고가/저가를 보정
- 날짜 오름차순 정렬


5. 지원 환경
------------
Windows 10 / 11 (64비트)
