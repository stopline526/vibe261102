## 2. 목표
- 방문자(채용 담당자, 협업자, 클라이언트)가 1분 안에 개발자의 핵심 역량을 파악할 수 있게 한다.
- Python·HTML5 중심의 기술 스택과 대표 프로젝트를 명확히 보여준다.

## 4. 기능 요구사항

### 4.1 페이지 구성 (싱글 페이지 + 섹션 네비게이션)
1. **Hero (메인)**
   - 이름, 한 줄 소개 (예: "Python & HTML5 개발자")
   - CTA 버튼: "프로젝트 보기", "연락하기"
2. **About (소개)**
   - 간단한 자기소개, 개발 철학, 관심 분야
3. **Skills (기술 스택)**
   - 주력: Python, HTML5
   - 보조: CSS3, JavaScript, Git 등 (추후 보완)
   - 숙련도 또는 사용 경험을 시각적으로 표시 (배지/카드)
4. **Projects (프로젝트)**
   - 프로젝트 카드: 제목, 설명, 사용 기술 태그, 썸네일, GitHub/데모 링크
   - 최소 3개 항목 (초기에는 placeholder)
5. **Contact (연락처)**
   - 이메일: `stopline526@gmail.com` (`mailto:` 링크)
   - 이메일 주소 복사 버튼
   - GitHub 등 외부 링크 (추후 추가)
6. **Footer**
   - 저작권 표기, 상단 이동 버튼

### 4.2 공통 기능
- 상단 고정 네비게이션 (섹션 앵커 이동, 부드러운 스크롤)
- 반응형 레이아웃 (모바일 / 태블릿 / 데스크톱)
- 다크/라이트 모드 토글 (시스템 설정 기본값)

## 5. 비기능 요구사항
| 항목 | 기준 |
|---|---|
| 성능 | Lighthouse Performance 90점 이상, 첫 화면 로드 2초 이내 |

## 6. 기술 스택 및 구조
- **프론트엔드**: HTML5, CSS3, Vanilla JavaScript
- **빌드/도구 (선택)**: Python 스크립트로 JSON 데이터 → 정적 HTML 생성 가능 (주력 분야 활용)
- **로컬 실행**: `python -m http.server`
- **배포**: GitHub Pages 또는 Netlify (정적 호스팅)
